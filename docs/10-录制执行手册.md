# 录制执行手册（10-08 当天用）

> **这份不是讲解稿，是操作流程。**
> 讲解词见 [09-答辩视频讲解稿](09-答辩视频讲解稿.md)，这里只管"当天怎么把片子录出来"。
>
> **核心原则：分段录。** 不要想着一次录完整片——
> 每一段都单独录、单独存文件，最后剪辑拼接。
> 这样任何一段录砸了，只重录那一段。

## 二、录制当天的启动顺序

> ⚠️ **顺序很重要**：Gazebo 要先起，等它完全就绪再起其他节点。
> 抢时间一起点，容易出现 spawn 失败或 TF 断链。

**第一步 · 终端 1：启动仿真（带界面）**

```bash
ros2 launch community_nav sim.launch.py
```

**等这两件事都发生再往下：**
1. 终端里出现 `Successfully spawned entity`
2. Gazebo 窗口出来了

**然后立刻做三件事：**
- **把 Gazebo 窗口拖小**（屏幕四分之一左右）
- **关掉阴影**
- 记下 Gazebo 窗口的位置，后面每段都放同一个位置

**第二步 · 终端 2：按要录的段选一个**

```bash
# 录"建图"相关段落时
ros2 launch community_nav mapping.launch.py

# 录"导航 / 巡检"相关段落时（默认不自动巡检）
ros2 launch community_nav navigation.launch.py
```

**等 RViz 窗口出来、左下角 `Fixed Frame` 没有警告再往下。**

**第三步 · 摆画面**

```
┌──────────────────────┬──────────────────────┐
│   Gazebo（小）        │    RViz（大）         │
└──────────────────────┴──────────────────────┘
```

**摆好之后，从头到尾不要再动窗口位置和大小。** 后面所有段落都用这个布局，
剪辑出来才整齐。

## 三、分镜录制顺序（★ 按这个顺序录最省事）

### 为什么顺序重要

**建图那一段只能录一次** —— 录完场地就有地图了，想再录"从零建图"
就得把地图删掉重来。所以：

> **先把"需要干净状态"的段落录完，再录那些可以反复重来的段落。**

### 建议顺序

| 顺序 | 段落 | 需要的状态 | 为什么排这个位置 |
|---|---|---|---|
| **1** | ③ 建图过程（含 ①② 场景镜头） | **地图还没建** | 只能来一次，必须先录 |
| **2** | ④ 建图代码讲解 | 无要求 | 纯录屏，建图刚结束顺手录 |
| **3** | 存档后重启 → ⑤ 导航与避障 | 已加载地图 | 建完图自然过渡到这里 |
| **4** | ⑥ 导航代码讲解 | 无要求 | 纯录屏 |
| **5** | ⑦ 识别过程（视觉组） | 需要视觉节点 | 视觉组配合 |
| **6** | ⑧⑨⑩⑪⑫ 方案答辩 | 全队出镜 + PPT | 最后集中录，可反复重来 |

## 四、每一段录之前的 30 秒检查

**养成习惯，每段都过一遍：**

- [ ] Gazebo 窗口还在、没崩
- [ ] RViz 里**激光点看得见**（说明定位/传感器正常）
- [ ] 录屏软件**正在录**（先确认在录，再开始讲）
- [ ] 麦克风**有电平**（对着说一句话看一眼）
- [ ] 这一段要展示的画面**已经在屏幕上**（别讲到一半才切窗口）

---

## 五、录砸了怎么办

**先把这条记住：复赛视频是**录播**，允许重录。没有任何惩罚。**

| 情况 | 处理 |
|---|---|
| 讲错词、卡壳 | **继续讲完这一段**，然后重录这一段。别中途停 |
| 车卡住 / 走歪了 | 重跑那一段，不用修 |
| Gazebo 崩了 | 重启仿真，**从当前段重录**。前面录好的不受影响 |
| RViz 不刷新 | 见 [06-排障指南](06-Gazebo与WSLg排障指南.md) §6.1 |
| 录到一半发现忘了开麦 | 重录这一段 |

**不要追求一次过。** 分段录的意义就是让每段都只有几十秒，压力小、重来便宜。

## 七、时间不够时的取舍

**如果 10-08 发现时间不够，按这个顺序砍：**

| 优先级 | 内容 | 说明 |
|---|---|---|
| **必录** | 建图过程、导航移动、Gazebo+RViz 同屏 | 直接对应 20 分，缺了没法评 |
| **必录** | 代码讲解段 | 规则明确要求"展示核心代码片段并语音讲解" |
| **尽量录** | 避障、红绿灯停车 | 明显加分点 |
| **可以简化** | 识别过程 | 视觉组负责，可以后补 |
| **可以先放** | 方案答辩段 | 这一段是 PPT 讲解，**不需要仿真在跑**，最晚也能补录 |

> **关键：方案答辩段不依赖仿真环境。** 万一仿真那边一直不稳，
> 先把答辩段录了（全队出镜 + PPT），至少保证下半部分完整。

## 八、一句话总结

> **分段录、先录不可重来的、每段录前确认在录。
> 录砸了就重录那一段，没有任何惩罚。**
